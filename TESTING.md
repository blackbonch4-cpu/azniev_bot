## 📋 Подготовка к тестированию

### 1. Создайте тестовый бот

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и создайте бота
4. Сохраните полученный **Bot Token**

### 2. Создайте тестовый приватный канал

1. Создайте новый приватный канал в Telegram
2. Добавьте вашего бота как администратора с правами:
   - ✅ Просмотр сообщений
   - ✅ Добавление участников
3. Получите ID канала:
   - Способ 1: Добавьте [@username_to_id_bot](https://t.me/username_to_id_bot) в канал
   - Способ 2: Перешлите любое сообщение из канала [@getidsbot](https://t.me/getidsbot)
   - ID будет выглядеть как: `-1001234567890`

### 3. Настройте .env файл

```bash
cd /Users/blackdany/telegram-webinar-bot

# Создайте .env файл из примера
cp .env.example .env

# Отредактируйте .env (используйте nano, vim или любой редактор)
nano .env
```

Минимальная конфигурация для тестирования:

```env
# Обязательные параметры
BOT_TOKEN=123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11
CHANNEL_ID=-1001234567890
ADMIN_IDS=ВАШ_TELEGRAM_ID

# Опциональные (можно оставить как есть для теста)
SUPPORT_GROUP_ID=-1001234567890
SUPPORT_TOPIC_ID=1
YOOKASSA_SHOP_ID=your_shop_id
YOOKASSA_SECRET_KEY=your_secret_key
GOOGLE_SHEETS_CREDS_FILE=credentials.json
GOOGLE_SHEET_ID=your_google_sheet_id
```

**Как получить свой Telegram ID:**
1. Напишите [@username_to_id_bot](https://t.me/username_to_id_bot)
2. Отправьте `/start`
3. Скопируйте ваш ID

### 4. Установите зависимости

```bash
# Создайте виртуальное окружение
python3 -m venv venv

# Активируйте его
source venv/bin/activate

# Установите зависимости
pip install -r requirements.txt
```

## 📱 Сценарии тестирования

### Сценарий 1: Регистрация нового пользователя БЕЗ подписки

1. **Откройте вашего бота** в Telegram
2. **Отправьте** `/start`
3. **Ожидаемое поведение:**
   - ❌ Бот сообщает что вы не подписаны на канал
   - 📢 Кнопка "Перейти в канал" (если канал публичный)
   - ✅ Кнопка "Проверить подписку"

### Сценарий 2: Подписка и повторная проверка

1. **Подпишитесь** на тестовый канал
2. **Нажмите** "Проверить подписку"
3. **Ожидаемое поведение:**
   - ✅ "Отлично! Вы подписаны на канал"
   - 👋 Приветственное сообщение
   - 📧 "Пожалуйста, укажите вашу электронную почту"

### Сценарий 3: Ввод некорректного email

1. **Введите** неправильный email (например: `test`)
2. **Ожидаемое поведение:**
   - ❌ "Некорректный email адрес!"
   - 📧 Повторный запрос email

### Сценарий 4: Успешная регистрация

1. **Введите** корректный email (например: `test@example.com`)
2. **Ожидаемое поведение:**
   - ✅ "Регистрация успешно завершена!"
   - 📋 Главное меню с кнопками:
     - 🎓 Вебинар
     - 🆘 Помощь

### Сценарий 5: Повторный /start зарегистрированного пользователя

1. **Отправьте** `/start` снова
2. **Ожидаемое поведение:**
   - 👋 "С возвращением, {ваше имя}!"
   - 📋 Главное меню (без повторного запроса email)

### Сценарий 6: Отписка от канала

1. **Отпишитесь** от тестового канала
2. **Отправьте** любое сообщение боту (например "Вебинар")
3. **Ожидаемое поведение:**
   - ❌ "Вы не подписаны на наш канал!"
   - 📢 Предложение подписаться снова


## ⚠️ Возможные проблемы и решения

### Проблема: Бот не проверяет подписку

**Решение:**
- Убедитесь что бот добавлен в канал как **администратор**
- Проверьте что у бота есть права "Просмотр сообщений"
- Проверьте что `CHANNEL_ID` в .env правильный (начинается с `-100`)

### Проблема: "Chat not found"

**Решение:**
- Неправильный CHANNEL_ID
- Бот не добавлен в канал
- Канал удален

### Проблема: Ошибка при сохранении в БД

**Решение:**
- Проверьте права доступа к файлу `database.db`
- Удалите `database.db` и запустите бота заново (БД пересоздастся)

### Проблема: ValidationError при запуске

**Решение:**
- Проверьте что все обязательные переменные в .env заполнены
- Проверьте правильность формата переменных
